Stock In — Inventory Receiving

Record incoming stock procurement. Automatically calls PL/SQL procedure INVENTORY_PKG.STOCK_IN

--
Updates product purchase cost if provided
Database Transaction Guarantee: Stock-in executes atomically inside Oracle DB. Updates product quantity and records a permanent movement entry in the same transaction.

Stock Out — Issue / Sales Dispatch

Record outgoing shipments or sales. Protected by Oracle pessimistic row lock (SELECT FOR UPDATE) to prevent negative balances

--
Concurrency Protection: PL/SQL procedure INVENTORY_PKG.STOCK_OUT validates stock availability against the locked row. If requested quantity exceeds stock, the operation is immediately rejected.
